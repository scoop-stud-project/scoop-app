# scoop-app
Autonomous student team-formation platform for hackathons and academic projects.

## Working process:
Step 1: Claim the Issue on the Board
In Project section open the Scoop Development Board (Kanban view)
Find the assigned issue in the Todo column
Read the Issue
Drag the card into the In Progress column
Step 2: Create a branch to work on your issue
Step 3: Complete the task in the Branch
Work on the task inside the appropriate repository folder:
For Text/Specs: Create or edit a Markdown file in docs/stage-2/ (e.g., docs/stage-2/non-functional-requirements.md).
To make a markdown file just copy your table to https://www.tablesgenerator.com/markdown_tables 
For Diagrams: Save the editable source file (e.g., use_cases.puml or use_cases.drawio) and an exported high-resolution .png inside docs/diagrams/.
Step 4: Commit and Push the Changes
Step 5: Open a Pull Request (PR)
